# Windhawk 系统资源告警

[English](README.md) · **简体中文**

*版本 0.8.5 · GPL-3.0-only · Windows 11 x64*

Windows 11 任务栏资源告警：CPU、内存、磁盘、GPU 或温度任一指标持续越线时，托盘旁显示一个透明的「图标+数值」；点击图标，可在圆角总表中查看完整读数。

![4K 桌面实景里的原生总表、任务栏告警与 GPU 独立折叠](docs/resource-overview-v0.8.5-desktop-4k.jpg)

## 监控范围

- CPU 负载、物理内存、提交内存
- 系统盘剩余空间、活动率、读写速度
- 每张 GPU 的负载、显存、核心温度（最多八张物理卡，各自独立）

传感器读数缺失或过期时，对应行自动省略。

## 表现

- 告警位于系统托盘一侧。恰好三项时收成一条窄列，四项以上每列两项、向左扩展。
- 文字与图标均为原生 XAML，任务栏内无底色，也无独立悬浮窗口。
- 无告警时任务栏零占用：无入口图标，无预留空间。
- 点击告警打开总表，三列：参数、当前值、近 15 分钟最值，严重与告警项靠前。内容保持单行，面板按最长文本自适应宽度；行数多时并排摆放，无需滚动或翻页。
- 最值来自滚动 15 分钟的有效样本：磁盘剩余空间取最低，其余取最高。窗口未满时按已有样本统计；数据只保存在内存，不生成历史文件。
- 每张 GPU 一条可折叠行：收起时只显示负载和显存，展开后显示温度及其余完整读数。

图标：芯片=CPU，内存条=物理内存，带加号的文档=提交内存，硬盘=剩余空间，仪表=磁盘活动率，向下箭头=持续写入，显示器=GPU，内存芯片=显存，温度计=温度。

## 默认阈值

| 指标 | 告警 | 严重 |
| --- | --- | --- |
| CPU 负载 | 95%，持续约 30 秒（允许回落 5 秒） | — |
| GPU 负载 | 95%，持续 30 秒 | — |
| 物理内存 | 可用低于 10% 且低于 4 GiB | 可用低于 1% 且低于 500 MiB |
| 提交内存 | 85% | 95% |
| 系统盘剩余空间 | 低于 10% 且低于 10 GiB | 低于 5% 且低于 3 GiB |
| 系统盘活动率 | 90%，持续 60 秒（允许回落 5 秒） | — |
| 系统盘写入速度 | ≥5 MiB/s，持续 180 秒（允许回落 5 秒） | — |
| 读取速度 | 只作诊断，不设统一阈值 | — |
| 显存 | 90% | 97% |
| GPU 核心温度 | 80°C | 87°C |
| CPU 温度 | 90°C | 95°C |

一般告警在状态持续 5 秒后出现，严重告警 2 秒；恢复需读数连续 10 秒有效。颜色：琥珀色=告警，红色=严重。

## 安装

1. 安装并打开 [Windhawk](https://windhawk.net/)。
2. 选择「创建新模组」（Create a new mod）。
3. 打开本仓库的 [system-resource-alert.wh.cpp](system-resource-alert.wh.cpp)，复制**全部内容**，把编辑器里的模板整份替换。
4. 按 **Ctrl+B** 编译并启用，再到模组设置页调整阈值。
5. 任务栏为空表示没有指标越线；告警出现后，点击图标打开总表。

仓库只提供源码、文档和那张模拟截图，不含预编译 DLL——首次编译与符号解析所需下载由 Windhawk 自行处理。升级同样整份替换并重新编译。

默认行高 18 DIP、行间距 0。要自定义行高，先启用 **Use custom row spacing**。

## 数据来源

| 读数 | 来源 |
| --- | --- |
| CPU、内存、提交量、进程/线程/句柄数 | Windows 系统 API |
| 系统盘剩余空间 | Windows 所在的那块盘，不固定指向私人路径 |
| 磁盘活动率、读写速度 | Windows PDH `LogicalDisk` 计数器；首个采样周期用于建立基线 |
| GPU 占用与显存 | 有 NVML 时优先使用，再配 PDH 计数器 |
| GPU 核心温度 | 视驱动支持，取自 NVML 或 Windows D3DKMT |
| CPU 温度（可选） | LibreHardwareMonitor 的本机 Web Server（默认端口 8085，可在设置里改），兼容旧版 WMI |

CPU 温度：安装并运行 [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor)，开启其 Web Server，模组读取 `http://127.0.0.1:8085/data.json`。HTTP 客户端只访问 localhost，无代理、重定向或自动认证；启动 LibreHardwareMonitor 与安装传感器驱动均需自行完成。未提供该服务时，CPU 温度行自动隐藏。GPU 热点温度、显存结温、主板与硬盘温度未纳入监测。

## 兼容性与边界

- 面向 Windows 11 x64 主显示器上的横向任务栏。
- 依赖任务栏内部结构，该结构随系统版本变动，Windows 更新或其他任务栏模组可能带来影响。遇到无法识别的结构会记录失败并停止附加，放弃猜测内存偏移或退回悬浮窗。
- 禁用模组会移除其控件并还原改动的布局。

## 隐私与反馈

模组只读取资源计数、显卡与驱动信息、系统盘状态、可选的本机温度服务，以及 Explorer 的任务栏布局（用于挂载原生控件）。全部数据只存于本机内存。仓库的发布范围见[隐私说明](PRIVACY.md)。

发现问题或有改进建议，请开 [Issue](https://github.com/SinCircle/windhawk-system-resource-alert/issues)，附上 Windows 与 Windhawk 版本及简短复现步骤。
